# Animation source notes

The homepage intro and content entrances are original, site-specific HTML/CSS/JavaScript implementations.

Design and performance research included:

- Connor Atherton, `loaders.css`: https://github.com/ConnorAtherton/loaders.css

That project is MIT licensed and emphasizes lightweight CSS animations using inexpensive transform and opacity changes. The website does not load the library or any third-party runtime; its pizza loader, timing, markup, styling, session behavior, and reduced-motion fallback were created specifically for Break Coffee & Food.
