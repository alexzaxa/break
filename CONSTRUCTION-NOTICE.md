# Menu construction notice

The animated notice on `menu.html` and `drinks.html` is an original, site-specific HTML/CSS implementation.

Design research included the following GitHub example:

- Bestulo, “Under Construction” pure CSS3 animated illustration: https://gist.github.com/Bestulo/c9b001a47440d74c97e47146627bd56f

No external image, script, or runtime dependency is used. The site implementation uses its own markup, styling, animation, responsive layout, and reduced-motion fallback.
